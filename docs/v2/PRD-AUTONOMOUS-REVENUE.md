# AWKN Marketing V2｜自主获客与营收增长产品扩展 PRD

> 状态：PROPOSED / NOT_IMPLEMENTED / NO_REVENUE_EVIDENCE  
> 目标：以最低可验证成本建立“需求→价值交付→收款→复购”证据闭环  
> 适用范围：Marketing 产品层；旧版 docs/PRD.md V1.2 原位保持

## 1. 业务裁决与边界
V2 探索两条业务流水线：
A. 企业公开、合法可用的需求信号 → 主体核验 → 适配判断 → 可核验方案 → 审批 → 合规触达 → 反馈 → 交易。
B. 已定价的标准化价值产品 → 可搜索/可访问的展示页 → 自助体验 → 支付 → 自动履约 → 售后 → 复购。

推荐第一轮以 B 自助服务完成真实收款验证，并用 A 进行有限的人工批准触达。不能把转化率、利润和媒体文章中的收入宣称当成事实。

## 3. 目标用户与购买触发点
优先：自由职业者、咨询顾问、刚起步的服务团队、缺少销售/营销运营岗位的中小企业。
典型触发：公开招采/招聘已显露需求；评价无人回复造成信誉成本；需要报价分析、基础商机研判或快速上线网站。
最低可销售单位：明确边界的单项交付，例如“公开采购需求匹配报告”“服务报价建议”“授权企业评价回复草稿”；禁止将未验证的营销收益写为交付承诺。
优先研究用户已经付费的替代方案，包括手工服务、外包人员、现成 SaaS。

## 4. 产品主链
### A 主动获客（受控外联）
合规来源注册 → 原始页面快照和时间戳 → 数据清洗/去重 → 需求分类与预算可见性 → 可交付性评分 → 草拟针对性提案及证据 → 人工确认收件主体/渠道/内容/频次 → 允许的发送工具 → 回复记录 → Outcome。
冷启动阶段每次发出均须逐条审批，禁止自动群发、冒充客户、规避平台限制和抓取受限个人联系方式。
单个 Task 可复用现有 Artifact、Evidence、Feedback、Outcome；外联记录以后续获准的业务 Port 落地，暂不能假设现有 operation 支持发信。

### B 无需主动联系的自助交易
需求证据 → 单一垂直产品定义 → 可信演示和清晰售价/交付时限 → 合规内容分发/用户主动访问 → 外部支付提供方结账 → 经签名验证的支付确认 → 幂等履约 → 用户取得成果 → 退款/售后记录 → 复购。
SEO 页面只在存在真实独立价值和质量审核时发布；内容数量、检索收录、AI 推荐引用均不得宣称必然实现。
支付事件由支付服务商真值确认；营销工具不得仅依浏览器返回页认定付款成功。

## 6. MVP 范围
MUST：一款有明码标价的自助服务产品；一条可追溯需求证据；草稿与审批；退款说明；付款真值；交付记录；真实收入及成本账；故障后可恢复；审计。
SHOULD：第二种获客渠道对照；一组受控外联；多版本报价试验；首单访谈。
COULD：第二款数字商品、内容渠道实验、获批的自动化触达。
LATER：批量群发、自动外呼、全量 CRM、广告平台、投研交易和七个独立 Bot 后台。

## 7. 权限与责任
R0 只读研究；R1 生成草稿；R2 人工确认并执行一次外部发送/发布；R3 外部付费或有不可逆影响的动作必须独立权限、预算与提供方许可。
默认 R0/R1；R2/R3 依赖 Workspace Grant + Capability + Approval + Idempotency + Receipt。发送、付款、发布、删除、退费不得由模型自行提升权限。
对外信息保证真实身份披露、合理频次、退订或停止联系路径及适用地区法规核查。跨境 B2B 邮件规则需逐个目标法域审查。

## 8. 单位经济与商业验收
营收净额 = 已确认到账 - 已退款/拒付 - 折让（币种、税处理单独披露）。
单笔贡献利润 = 实收净额 - 平台与支付费用 - 模型/算力 - 获客可归因成本 - 履约成本 - 退款风险成本 - 客服人工。
月度净现金流需另计固定支出和付款结算周期。CAC、转化率、回本期、续费率记录分子分母；样本不足标 UNKNOWN。
成功的最低证据：独立客户真实付款、可交付服务、付款与回款可查、客户取得并使用成果、扣除成本后贡献利润可计算。营销访问数与内容数不能代替成交。

## 9. 实验设计
48 小时：从原始需求选一项服务；制作一个可访问演示或受控结账页面；配置签名支付沙箱与履约样例；登记 10 条合法来源需求及证据，完成 3 份可人工审阅草稿。全部属于工程实验，不能宣称真实销售。
14 天：开展定价访谈/真实用户购买验证（需已授权发布）；记录访问、试用、申请、成交、退款和人工成本；设置停止条件。
30 天：比较 A 与 B 的完整单笔贡献利润、回款周期、投诉/退订、客户满意度和复购；仅依据真实样本调整阈值。
对照组与分桶抽样应在实验前定义，禁止只展示成功案例或临时修改定义。

## 10. 验收与证伪
G1 来源合法、可复核且有时间戳；G2 客户身份与联系方式用途合规；G3 未审批外发=0；G4 付款伪成功=0；G5 重试重复发信/收费/交付=0；G6 撤权访问=0；G7 历史 V1 指标回归无新增失败。
业务失败可接受：无人付款、价格过高、履约亏损、渠道被拒。若无法核实合规或无法取得可信回款，停止对外扩量，状态 HOLD。
工程与营销观察分离：文档审查通过只表示 SPEC_READY，不表示 BUSINESS_VALIDATED。
